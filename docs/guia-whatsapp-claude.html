2. Configuració a Meta (WhatsApp Cloud API)

  1. Aneu a developers.facebook.com > Les meves aplicacions > Crea una aplicació.
  2. Trieu el cas d'ús Connecta amb els clients a través de WhatsApp (si no apareix: Altres > Negoci). Poseu-li un nom (ex: Prova Bot Claude), vinculeu-hi la cartera d'empresa i creeu l'app.
  3. Al menú esquerre: WhatsApp > Configuració de l'API (API Setup). Anoteu aquestes dades en un lloc segur:
    • Token d'accés temporal (Genera el token d'accés). Caduca cada 24 h; per a proves de més d'un dia, vegeu el punt 8.
    • Phone Number ID (identificador del número de proves +1 555...). Atenció: no és el número de telèfon, és un ID llarg.
  4. A A / To > Administra la llista de números de telèfon, afegiu els mòbils de l'equip (màxim 5) i confirmeu el codi que arriba per WhatsApp. Només aquests números podran parlar amb el bot.
  5. A Configuració de l'app > Bàsica, copieu la Clau secreta de l'app (App Secret). El bot la fa servir per comprovar que els missatges vénen de Meta.
  6. Inventeu una paraula de verificació qualsevol (ex: prova-bot-2026). Serà el VERIFY_TOKEN.

El webhook de Meta es configura al punt 6, quan el bot ja estigui publicat.

3. Clau d'API de Claude

  1. Entreu a platform.claude.com, afegiu crèdit (mínim 5 $) a Billing.
  2. A API Keys > Create Key, poseu-li un nom (ex: bot-whatsapp) i copieu-la. Només es mostra una vegada.
  3. Recomanat: a Limits, poseu un límit de despesa mensual (ex: 10 $) per evitar sorpreses.

// Bot de WhatsApp amb Claude, sobre Cloudflare Workers.
// Flux: Meta (webhook) -> aquest Worker -> Claude -> WhatsApp Cloud API.

import Anthropic from "@anthropic-ai/sdk";

const HISTORY_TTL_SECONDS = 24 * 60 * 60; // la conversa s'oblida després de 24 h sense missatges
const SEEN_IDS_KEPT = 20; // IDs de missatges recordats per evitar respondre dues vegades
const RESET_WORDS = ["/reset", "reset", "reinicia"];

export default {
  async fetch(request, env, ctx) {
    const url = new URL(request.url);

    // 1) Verificació del webhook: Meta la fa una vegada, en desar la Callback URL.
    if (request.method === "GET") {
      const mode = url.searchParams.get("hub.mode");
      const token = url.searchParams.get("hub.verify_token");
      if (mode === "subscribe" && token && token === env.VERIFY_TOKEN) {
        return new Response(url.searchParams.get("hub.challenge") ?? "", { status: 200 });
      }
      return new Response("Forbidden", { status: 403 });
    }

    if (request.method !== "POST") {
      return new Response("Method Not Allowed", { status: 405 });
    }

    // 2) Comprovar que la petició ve realment de Meta (signatura amb l'App Secret).
    const raw = await request.text();
    const signature = request.headers.get("x-hub-signature-256");
    if (!(await isValidSignature(raw, signature, env.APP_SECRET))) {
      console.warn("Signatura invàlida: petició rebutjada");
      return new Response("Invalid signature", { status: 401 });
    }

    let body;
    try {
      body = JSON.parse(raw);
    } catch {
      return new Response("Bad Request", { status: 400 });
    }

    // 3) Respondre 200 de seguida (si no, Meta reintenta) i treballar en segon pla.
    ctx.waitUntil(
      handleWebhook(body, env).catch((err) => console.error("Error processant el webhook:", err))
    );
    return new Response("OK", { status: 200 });
  },
};

export async function handleWebhook(body, env) {
  for (const entry of body.entry ?? []) {
    for (const change of entry.changes ?? []) {
      const value = change.value ?? {};
      // Els avisos d'estat (enviat, entregat, llegit) arriben a `statuses`, no a `messages`: s'ignoren.
      for (const message of value.messages ?? []) {
        await handleMessage(message, env);
      }
    }
  }
}

async function handleMessage(message, env) {
  const from = message.from; // número de l'usuari, en format internacional sense "+"
  const key = `conv:${from}`;
  const state = (await env.CONVERSES.get(key, "json")) ?? { history: [], seen: [] };

  // Evitar respostes duplicades si Meta reenvia el mateix missatge.
  if (state.seen.includes(message.id)) {
    console.log(`Missatge ${message.id} ja processat, s'ignora`);
    return;
  }
  state.seen = [...state.seen, message.id].slice(-SEEN_IDS_KEPT);

  if (message.type !== "text") {
    await sendWhatsAppText(env, from, "De moment només puc llegir missatges de text. Me'l pots escriure? 🙂");
    await saveState(env, key, state);
    return;
  }

  const text = (message.text?.body ?? "").trim();
  if (!text) return;

  if (RESET_WORDS.includes(text.toLowerCase())) {
    state.history = [];
    await sendWhatsAppText(env, from, "Fet! He oblidat la conversa anterior. En què et puc ajudar?");
    await saveState(env, key, state);
    return;
  }

  const messages = [...state.history, { role: "user", content: text }];

  let reply;
  try {
    reply = await askClaude(env, messages);
  } catch (err) {
    console.error("Error cridant Claude:", err);
    await sendWhatsAppText(env, from, "Ara mateix no puc respondre. Torna-ho a provar d'aquí a una estona, si us plau.");
    await saveState(env, key, state); // es desa l'ID per no reintentar en bucle, però no l'historial
    return;
  }

  await sendWhatsAppText(env, from, reply);

  // Guardar els últims torns (parells usuari/assistent) perquè el bot recordi el context.
  const maxMessages = Math.max(0, Number(env.HISTORY_TURNS ?? 10)) * 2;
  state.history = [...messages, { role: "assistant", content: reply }].slice(-maxMessages);
  await saveState(env, key, state);
}

async function askClaude(env, messages) {
  const client = new Anthropic({ apiKey: env.ANTHROPIC_API_KEY });
  const response = await client.messages.create({
    model: env.MODEL ?? "claude-haiku-5-5",
    max_tokens: 1024,
    // Xat senzill: sense raonament intern i esforç baix = respostes ràpides i barates.
    thinking: { type: "disabled" },
    output_config: { effort: "low" },
    system: env.SYSTEM_PROMPT,
    messages,
  });

  if (response.stop_reason === "refusal") {
    return "Ho sento, no puc ajudar-te amb això. Un agent de l'equip es posarà en contacte amb tu.";
  }

  const text = response.content
    .filter((block) => block.type === "text")
    .map((block) => block.text)
    .join("")
    .trim();

  return text || "Perdona, no t'he entès. Ho pots dir d'una altra manera?";
}

async function sendWhatsAppText(env, to, body) {
  const version = env.GRAPH_VERSION ?? "v23.0";
  const res = await fetch(`https://graph.facebook.com/${version}/${env.PHONE_NUMBER_ID}/messages`, {
    method: "POST",
    headers: {
      Authorization: `Bearer ${env.WHATSAPP_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      messaging_product: "whatsapp",
      to,
      type: "text",
      text: { body: body.slice(0, 4096) }, // límit de WhatsApp per missatge de text
    }),
  });
  if (!res.ok) {
    // Error típic: 401 = token caducat; 131030 = número no afegit a la llista de proves.
    console.error(`Error enviant a WhatsApp (${res.status}):`, await res.text());
  }
}

async function saveState(env, key, state) {
  await env.CONVERSES.put(key, JSON.stringify(state), { expirationTtl: HISTORY_TTL_SECONDS });
}

export async function isValidSignature(raw, header, secret) {
  if (!header || !secret || !header.startsWith("sha256=")) return false;
  const key = await crypto.subtle.importKey(
    "raw",
    new TextEncoder().encode(secret),
    { name: "HMAC", hash: "SHA-256" },
    false,
    ["sign"]
  );
  const mac = await crypto.subtle.sign("HMAC", key, new TextEncoder().encode(raw));
  const expected = "sha256=" + [...new Uint8Array(mac)].map((b) => b.toString(16).padStart(2, "0")).join("");
  // Comparació de temps constant
  if (expected.length !== header.length) return false;
  let diff = 0;
  for (let i = 0; i < expected.length; i++) diff |= expected.charCodeAt(i) ^ header.charCodeAt(i);
  return diff === 0;
}

5. Publicar el bot a Cloudflare

5.1 Iniciar sessió

Obre el navegador per autoritzar la terminal. Si no teniu compte de Cloudflare, el podeu crear en aquest moment (gratuït).

npx wrangler login

5.2 Crear la memòria de converses (KV)

npx wrangler kv namespace create CONVERSES

La comanda mostra un id (una cadena llarga). Enganxeu-lo a wrangler.toml, en lloc de POSEU_AQUI_L_ID_DEL_KV.

5.3 Guardar les claus com a secrets

Cada comanda us demana el valor; enganxeu-lo i premeu Enter. Les claus queden xifrades a Cloudflare i no apareixen enlloc del codi.

npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler secret put WHATSAPP_TOKEN
npx wrangler secret put PHONE_NUMBER_ID
npx wrangler secret put APP_SECRET
npx wrangler secret put VERIFY_TOKEN

La primera vegada, Wrangler pot preguntar si voleu crear el Worker. Responeu que sí.

5.4 Publicar

npx wrangler deploy

Al final mostra la URL del bot, semblant a https://whatsapp-claude-bot.el-vostre-subdomini.workers.dev. Copieu-la per al pas següent.

6. Connectar el webhook de Meta

  1. A Meta for Developers: WhatsApp > Configuració (Configuration) > Webhook > Edita.
  2. URL de devolució de trucada (Callback URL): la URL del Worker del pas 5.4.
  3. Token de verificació: la mateixa paraula que heu posat a VERIFY_TOKEN.
  4. Feu clic a Verifica i desa. Si dona error, vegeu la taula del punt 9.
  5. A Camps del webhook, busqueu messages i activeu Subscriu.

7. Provar-ho

  1. En una terminal, obriu els logs en directe per veure què passa: 
    npx wrangler tail
  2. Des d'un mòbil autoritzat, envieu un WhatsApp al número +1 555... de Meta.
  3. En pocs segons rebreu la resposta de Claude. Feu una segona pregunta relacionada: el bot recorda el context.
  4. Per començar una conversa de zero, escriviu reset.

Personalitzar el bot

  • Instruccions i to: editeu SYSTEM_PROMPT a wrangler.toml. Podeu afegir-hi horaris, serveis, preus o preguntes freqüents de l'empresa.
  • Memòria: HISTORY_TURNS (torns recordats, per defecte 10).
  • Després de cada canvi, torneu a publicar amb npx wrangler deploy.

8. Token permanent (per a proves de més d'un dia)

El token temporal caduca en 24 h i el bot deixa de respondre (als logs veureu un error 401). Per evitar-ho:

  1. A Meta Business Suite > Configuració del negoci > Usuaris del sistema, creeu un usuari del sistema (rol administrador).
  2. Assigneu-li l'app i el compte de WhatsApp (Afegeix actius).
  3. Genera un token nou: trieu l'app, caducitat Mai, i els permisos whatsapp_business_messaging i whatsapp_business_management.
  4. Substituïu el token a Cloudflare (s'aplica a l'instant, sense tornar a publicar): 
    npx wrangler secret put WHATSAPP_TOKEN
